A complete Spider-Gwen (*Into the Spider-Verse*) themed superhero costume modification for **!Ω Factorial Omega: My Dystopian Robot Girlfriend (MDRG)**.

---

## 🎮 Features

- **Full Gwen Stacy Hooded Suit:** High-detail hooded upper outer garment (`UpperBodyOuter`) and matching spider-suit textures.
- Full texture rendering across all game positions and interaction scenes.
- Verified 100% working on MDRG version **v0.97.12** (Target: `0.97.11`).

---

## 📥 Installation

1. Go to the [**Releases**](https://github.com/MDRG-MODS/spiger-gwen-costume/releases) page and download the release zip (`00dc1614-23cc-4b36-bca9-6cd3f7300a6e.zip` or `Spider_Gwen_Costume_v1.0.0.zip`).
2. Navigate to your MDRG installation directory:
   ```text
   .../My Dystopian Robot Girlfriend/FactorialOmega_Data/StreamingAssets/Mods/
   ```
3. Extract the `.zip` into your `Mods/` directory so that `mod.json` is located at:
   ```text
   .../StreamingAssets/Mods/Spider-Gwen Costume/mod.json
   ```
4. Launch the game and purchase/equip the costume from the Clothier.
