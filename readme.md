A complete Spider-Gwen (*Into the Spider-Verse*) themed superhero costume modification for **!Ω Factorial Omega: My Dystopian Robot Girlfriend (MDRG)**.

---

## 🎮 Features

- **Full Gwen Stacy Hooded Suit:** High-detail hooded upper outer garment (`UpperBodyOuter`) and matching spider-suit textures.
- Full texture rendering across all game positions and interaction scenes.
- Compatible with MDRG version **v0.97.12** (Target: `0.97.11`).

---

## ⚙️ Mod Type

This is an **Internal Mod**, designed to be imported, enabled, and managed directly using MDRG's built-in in-game mod manager (available on PC, Mac, and Android). It does not require external modding tools or loaders such as LemonLoader.

Ready-to-use mod packages are available under the [**Releases**](https://github.com/MDRG-MODS/spiger-gwen-costume/releases) tab.
